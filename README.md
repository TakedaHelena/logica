Projeto da disciplina de Lógica e Técnicas de programação do terceiro trimestre
IFSP campus Campinas
Autores: Hélio Cruz e Helena Takeda
Titulo: Vateslogicum
Resumo: Uma espécie de "Akinator", um famoso genio conhecido internet afora por adivinhar todos os personagens que o usuário pensa. Nossa versão é uma experimental, já que o original tem uma base de dados e usuário nas bases de dezenas de milhôes.
Escolhemos utilizar a base de nossa própria escola e turma, limitada para ser mais palpável, mas ainda assim sendo escalável.
A lógica por traz da nossa versão é a mesma do Cara-a-Cara, perguntas que diminuem em aproximadamente 50% as possibilidades de resposta.
